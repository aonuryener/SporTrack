**  English

This project is my ""first professional project"" in the software world.

*** "" AI-Human Collaboration Experiment
This application has been developed to test how professional and functional results can emerge from ""AI-Human Collaboration"".

*   ""Vision & Design:"" Conceptualized by ""Ahmet Onur Yener"".

**** Future Plans (Roadmap)

*   ""Centralized Database:"" Data synchronization between different devices.
*   ""Advanced API Integrations:"" Fetching data from wearable technology (smartwatches, etc.).
*   ""Mobile Application:"" Transitioning to mobile platforms with React Native or Flutter.

"I continue to develop and learn!"
